# 小人国 · 等距城市建造

一个用纯 HTML + Canvas 手写的等距（2.5D）城市建造小游戏，**128 × 128 格**大地图。零依赖、零构建，双击 `index.html` 即可在浏览器里玩，也可以用 `start-game.cmd` 以独立应用窗口启动并把存档写成独立文件。

休闲向设计：**不会破产、没有失败**，只有城市慢慢长大。

## 玩法

- 先铺道路，再把住宅盖在道路（或车站）旁边，居民才会入住
- 住宅住满且幸福度够高时会自动升级：4 → 8 → 12 人
- 公园、树木、医院、学校、消防、警局提升幸福度；工厂、电站、机场、物流园带来污染或噪音
- 商店、写字楼、物流园、车站、港口、机场、体育场提供收入；电力不足会拖慢人口增长
- 轨道 + 车站 + 换乘枢纽可以搭出一整张捷运路网，车站也算「道路接入」
- 高架可以立体跨过地面道路、水面与树木，匝道负责把高架接回地面

## 操作

- 左键点击放置，按住拖动可以连续铺设（铺路 / 铺轨道很方便）
- 右键 / 中键拖动平移视角，滚轮缩放（缩得很远时自动切换到简化渲染）
- 手机：单指拖动平移，轻点建造
- 快捷键：`1`~`9` 选择当前分类里的工具，`X` 拆除，`空格` 暂停
- 底部分页切换「基础 / 道路 / 交通 / 市政 / 地标 / 产业」

## 存档

- 点 💾 打开存档面板，共 8 个存档槽，可分别保存 / 读取 / 删除
- 支持导出 / 导入 JSON 存档文件
- 用 `start-game.cmd` 启动时，每个存档就是一个独立的 `saves/slotN.json` 文件；直接双击 `index.html` 时退回浏览器 localStorage
- 每 6 秒自动保存到当前存档槽
- 旧版存档（24 × 24、32 × 32）会自动迁移到新地图中央

## 本地运行

独立应用窗口（推荐，带本地文件存档）：

```powershell
.\start-game.cmd
# 或
python server.py
```

只想用浏览器：

```powershell
python -m http.server 8000
```

## 实现说明

全部图形由 Canvas 2D 现画（没有任何外部图片资源）：

- 菱形瓦片网格 + 逆变换拾取，按 `i + j` 对角线顺序绘制以获得正确的遮挡关系
- 高架存在独立的 `upper` 图层，与地面同帧绘制，因此可以跨过地面建筑与道路
- 缩远到一定程度后，地面改用预先烘焙的贴图、建筑改用简化色块，128 × 128 地图也能跑满帧
- 逻辑以 0.2 秒定步长推进，渲染走 `requestAnimationFrame`
- 地图、存档、建筑参数都在 `game.js` 顶部，方便调平衡
