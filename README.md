# 小人国 · 等距城市建造

一个用纯 HTML + Canvas 手写的等距（2.5D）城市建造小游戏。零依赖、零构建，双击 `index.html` 即可在浏览器里玩，也可以直接丢到 GitHub Pages 上。

休闲向设计：**不会破产、没有失败**，只有城市慢慢长大。

## 玩法

- 先铺道路，再把住宅盖在道路旁边，居民才会入住
- 住宅住满且幸福度够高时会自动升级：4 → 8 → 12 人
- 公园与树木提升附近住宅的幸福度；工厂和电站会带来污染
- 商店和工厂提供稳定收入；电力不足会拖慢人口增长
- 进度每 6 秒自动存到浏览器 localStorage，`↺` 可以换一张新地图

| 建筑 | 造价 | 作用 |
| --- | --- | --- |
| 🛣️ 道路 | ¥20 | 住宅必须紧挨道路才会有人入住 |
| 🏠 住宅 | ¥150 | 容纳 4 / 8 / 12 人，住满后自动升级 |
| 🏪 商店 | ¥300 | 持续收入 +1.2/秒 |
| 🏭 工厂 | ¥450 | 收入 +1.8/秒，会污染周边 |
| ⚡ 电站 | ¥600 | 供电 +25，稍有污染 |
| 🌳 公园 | ¥120 | 提升附近住宅的幸福度 |
| 🌲 树木 | ¥30 | 装饰用，少量幸福度 |
| 🧨 拆除 | — | 退还 50% 建造费用 |

## 操作

- 左键点击放置，按住拖动可以连续铺设（铺路很方便）
- 右键 / 中键拖动平移视角，滚轮缩放
- 手机：单指拖动平移，轻点建造
- 快捷键：`1`~`7` 切换工具，`X` 拆除，`空格` 暂停

## 实现说明

单文件实现，全部图形由 Canvas 2D 现画（没有任何外部图片资源）：

- 菱形瓦片网格 + 逆变换拾取，按 `i + j` 对角线顺序绘制以获得正确的遮挡关系
- 逻辑以 0.2 秒定步长推进，渲染走 `requestAnimationFrame`
- 地图、存档、建筑参数都在脚本顶部，方便调平衡

## 本地运行

直接双击 `index.html`，或用任意静态服务器：

```powershell
python -m http.server 8000
```
