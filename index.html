小人国 · 等距城市建造

128 × 128 格的大地图：可以铺出一整张捷运路网，再把城市填满。这个模式很休闲：永远不会破产，只有城市慢慢长大。
  • 建造：左键点击放置，按住拖动可连续铺设（铺路 / 铺轨道很方便）
  • 视角：右键 / 中键拖动平移，滚轮缩放，手机单指拖动平移、轻点建造
  • 快捷键：1~9 选择当前分类里的工具，X 拆除，空格 暂停
  • 分类：底部分页切换 基础 / 道路 / 交通 / 市政 / 地标 / 产业
  • 道路：小路最便宜；大道四车道，路边住宅更满意；高架可跨过道路与水面，匝道负责把高架接回地面
  • 住宅需要紧挨道路或车站才会有人入住；住满且幸福度 ≥ 58 时会自动升级（4 → 8 → 12 人）
  • 交通：先铺轨道，车站要接在轨道上，换乘枢纽至少接两段轨道；车站也能给住宅接通道路
  • 港口要建在水边，机场要挨着道路；高塔 / 体育场是全城地标
  • 公园 / 树木 / 医院 / 学校 / 消防 / 警局提升幸福度；工厂 / 电站 / 机场 / 物流园带来污染或噪音
  • 存档：点 💾 打开 8 个存档槽，可分别保存 / 读取 / 删除，也能导入导出 JSON 文件
  • 进度每 6 秒自动存入当前存档槽，点 ↺ 可以换一张新地图
